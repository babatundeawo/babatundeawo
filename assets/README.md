# assets

Images used by the profile README. Each image comes in a light and a dark version, and GitHub shows the one that matches the visitor's theme.

| File | Used for |
| --- | --- |
| `banner-light.svg`, `banner-dark.svg` | Header banner |
| `tagline-light.svg`, `tagline-dark.svg` | Rotating one-line tagline under the banner |
| `stats-light.svg`, `stats-dark.svg` | "GitHub at a glance" card, refreshed weekly by the **Update profile stats** workflow |
